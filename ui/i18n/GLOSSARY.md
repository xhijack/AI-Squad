# Translating The AI Squad UI

Keys are the English text (`t('Send task')`). `en.json` lists every key (value = the key); `id.json` has the Bahasa Indonesia text for each.

## Style for Bahasa Indonesia

- Natural, friendly-professional, addressing the owner as **kamu** (never "Anda"). Short, like good app copy.
- No emoji. Keep the punctuation of the English (ending colon, ellipsis, "·").
- Placeholders `{name}` stay exactly as they are. HTML tags in a key (`<b>`, `<code>`) stay in the translation, around the matching words.
- Do not translate: agent and role names, model names (opus, sonnet), file names and paths, commands, code, keyboard keys (Ctrl, Enter, Q / E), brand names (Claude Code, ElevenLabs, GitHub), units (GB, MB, %, SP).
