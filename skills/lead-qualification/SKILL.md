# Lead qualification

## For each prospect (a company, then the buyer role)
1. **Fit:** segment, size, region and other ICP criteria: yes / no / unknown, each with a source link.
2. **Signals:** recent events that suggest need (hiring, funding, new branch, technology change), with source and date.
3. **Disqualifiers** from the ICP: if one applies, record "disqualified: <reason>" and stop.
4. **Score:** A (strong fit and a current signal), B (fit, no signal), C (partial fit), or disqualified.

## Rules
- Public business information only; respect the sites' terms. No guessing of personal emails.
- Record leads only in the CRM or the CRM import file named in `docs/PIPELINE.md`, never in logs, commits or messages; refer to them by CRM id.
- Hand off counts per segment and score, and the most common disqualification reasons.
- Never contact a prospect.
