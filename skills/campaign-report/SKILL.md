# Campaign report

Write it in `docs/reports/<period>-<campaign>.md`.

## Sections
1. **Summary:** three lines: what ran, the main result, the decision needed.
2. **KPIs:** table of KPI · target · actual · change versus the previous period · source · date range.
3. **What worked and what did not**, per channel, with the evidence (top pieces, weak pieces).
4. **Spend** (if any) and cost per result.
5. **Caveats:** missing data, sampling, tracking changes, small numbers.
6. **Next:** three recommendations, each with the KPI it should move.

Numbers come from the platforms' own reports; never estimate them as facts. No personal data in the report.
