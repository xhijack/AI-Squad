# Finance working files

Owner only. One file per period in each folder:

- `close/<yyyy-mm>.md` month-end close checklist
- `cash-flow.md` the next 8 weeks, every figure with its source
- `receivables/<date>.md` overdue invoices and DRAFT follow-ups (the owner sends them)
- `budget/<date>.md` budget vs actual notes
- `bank/` statements placed by the owner; `reconciliation/<yyyy-mm>.md` the bookkeeper's result
- `tax/<yyyy-mm>.md` tax worksheets (drafts; nothing is filed from here)
