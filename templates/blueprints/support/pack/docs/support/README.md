# Support working files

Ticket ids only: customers' personal data stays in the help desk or ERPNext.

- `triage/<date>.md` the morning triage
- `drafts/<ticket-id>.md` reply drafts (sent only after approval, or in automatic mode with an APPROVED KB article)
- `reports/<date>.md` the weekly support report
- `kb-gaps-<date>.md` questions without an article
