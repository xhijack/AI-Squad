# Contracts

One file per contract: `<yyyy-mm>-<party>-<type>.md`, copied from a template in the Company Brain (`legal/templates/`).
The first line after the title is `STATUS: DRAFT`. The desk may set `STATUS: READY FOR REVIEW`; only the owner approves
(in the app). A contract marked APPROVED any other way, or changed after its approval, goes back to DRAFT.
